The simulation of Section VIII-F of the manuscript is a discrete-event model written in Python. Table~\ref{tab:simparams} lists its parameters. Network delays follow a constant plus a log-normal term on the field link (sensor to gateway) and on the path from the gateway to the twin; the latter is first-in first-out, as over a TCP connection. Sensor and gateway clocks have constant offsets drawn uniformly within $\pm 5$\,ms of the twin clock. In C0, the gateway stamps an update when it receives it from the sensor; under attack, it stamps the update when it forwards it, which hides the delay or the replay. In C1-C3, the source signature covers the sequence number, the generation timestamp, and the value, so a rewritten timestamp invalidates the signature and a non-increasing sequence number is rejected. The default simulation compares measured age directly with $D$; a supplementary check adds the known 5\,ms clock margin of the conservative freshness test in the manuscript. The residual of C3 compares the measured vibration with the vibration predicted from the spindle current through the linear coupling of the model. The code also contains the closed-form CoAP analysis and its Monte Carlo check (Section VII-B of the manuscript) and the computation of COSE message sizes (Section V-B of the manuscript).
